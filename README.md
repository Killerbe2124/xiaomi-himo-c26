# Xiaomi Himo C26 Landing Page

## Описание
Этот репозиторий содержит код адаптивного лендинга для электровелосипеда **Xiaomi Himo C26**. Проект демонстрирует визуальные особенности, характеристики и преимущества продукта с помощью современного веб-интерфейса.

## Технологии
- **HTML5** – семантическая разметка страницы
- **CSS3** – стилизация, анимации и адаптивная верстка
- **JavaScript** – интерактивные элементы и динамическое поведение

## Структура проекта
```text
xiaomi-himo-c26/
├── index.html          # Главная страница лендинга
├── css/                # Таблицы стилей
├── js/                 # Скрипты для интерактивности
├── images/             # Изображения и медиа-ресурсы
└── .DS_Store           # Системный файл macOS (можно добавить в .gitignore)
